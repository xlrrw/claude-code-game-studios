# Game Brief — «Последний Маяк» (The Last Lighthouse)

**Платформа:** Roblox (Luau) · **Жанр:** совместный симулятор-сборщик + паркур + питомцы
**Аудитория:** 9–16 лет · **Код:** `roblox/LastLighthouse/` · **Версия:** 0.1.0 (Глава I)

> Roblox — не один из движков шаблона студии (Godot / Unity / Unreal), поэтому `project.yaml`
> не менялся, а код лежит отдельно, в `roblox/`. Цифры баланса — в `src/shared/Config.lua`.

## Логлайн
Когда-то в ночном небе горела тысяча маяков. Тень погасила их все, кроме одного.
Игроки — юные Смотрители: собирают звёздный свет, кормят им последний Маяк
и вместе не дают Тени погрузить парящие острова в Облачное море.

## Столпы
1. **Красота ночи.** Северное сияние, луч Маяка, неон кристаллов — каждый скриншот как обложка.
2. **Вместе сильнее.** Маяк и Тень — общие для сервера. Мой вклад помогает всем.
3. **Тайна.** Записки первого Смотрителя ведут к разгадке: Тень — это он сам, оставшийся в одиночестве.
4. **Честный донат.** Ускоряет и украшает, но не запирает контент. Никаких лотерей за робуксы.

## Сюжет (Глава I)
- **Вступление.** Игрок приходит в себя у Маяка. Старый Орин рассказывает о Тени и о том, что этот маяк — последний.
- **Записки 1–5.** История первого Смотрителя: друзья Лира и Тео улетели зажигать дальние маяки и не вернулись;
  он остался один, и его тень росла. Последняя записка: *«Тьма приходит к тем, кто остался один»*.
- **Осколок Звезды** на вершине Рушащегося острова — крючок к Главе II (летающий корабль).
- **Глава II (план):** корабль из Осколков, дальние острова, встреча с Тенью. Финал — не победить её, а позвать домой.

## Главный цикл
Собрать осколки света (сбор по радиусу) → потратить свет (улучшения, духи) **или** вложить его в Маяк
(опыт → ранг → вечный бонус +10%; уровень Маяка → бонус всему серверу) → открыть новые места и записки → повторить.

**Мета-события:** «Тень наступает» каждые 7–10 минут — 2 минуты на общую цель
(победа: +50% света всем на 5 минут; провал: Маяк теряет 15% огня).

## Системы
| Система | Файл | Суть |
|---|---|---|
| Сохранения | `server/DataService.lua` | DataStore, автосейв раз в 2 минуты, без перезаписи при сбое загрузки |
| Свет, Маяк, Тень | `server/LightService.lua` | сервер сам проверяет сбор, 8 уровней Маяка, событие |
| Магазин | `server/ShopService.lua` | 2 улучшения, 3 духа за свет |
| Духи | `server/PetService.lua` | процедурные модели, AlignPosition, физика у владельца |
| Паркур | `server/ObbyService.lua` | падающие и мигающие платформы, батуты, чекпоинты, возврат из пустоты |
| Сюжет | `server/StoryService.lua` | записки, Орин с подсказками по прогрессу |
| Донат | `server/MonetizationService.lua` | ProcessReceipt выдаёт товар ровно один раз, геймпассы |
| Интерфейс, эффекты | `client/*` | HUD, магазин, диалоги, катсцена, двойной прыжок |

## Множитель света (формула)
`mult = 1 + VIP(1.0) + Premium(0.1) + (уровеньМаяка−1)·0.05 + (ранг−1)·0.10 + Σ бонусов духов + бусты(1.0 / 0.5)`
Награда за осколок = `round(ценность × mult)`; радиус = `6 + 1.2·улучшение + Σ радиус духов`.
