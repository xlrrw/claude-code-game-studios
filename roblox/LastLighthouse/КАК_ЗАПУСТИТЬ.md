# 🗼 Последний Маяк — как запустить и начать зарабатывать

Инструкция для новичка, по шагам. Займёт около 20 минут.

---

## Шаг 1. Установка игры (5 минут)

1. Открой **Roblox Studio** → **New** → **Baseplate**. Нужно новое, пустое место.
2. Сверху открой вкладку **View** и включи две панели:
   - **Command Bar** — длинная строка внизу экрана, сюда будем вставлять установщик;
   - **Output** — окно с сообщениями, в нём видно, что всё прошло хорошо.
3. Открой файл **`LastLighthouse_Installer.txt`** в Блокноте.
   Нажми **Ctrl+A** (выделить всё), затем **Ctrl+C** (скопировать).
4. Кликни в **Command Bar**, нажми **Ctrl+V** (вставить), а потом **Enter**.
5. Подожди 10–30 секунд, Studio может немного «подвиснуть» — это нормально.
   В **Output** должно появиться:
   `✦✦✦ УСТАНОВКА ЗАВЕРШЕНА! ...`
6. Нажми **Play** ▶ — и играй! 🎉

> **Если Command Bar не принимает такой длинный текст** (ничего не происходит или Studio
> зависает), используй запасной вариант. Это три файла поменьше в папке `installer_parts/`.
> Вставляй их в Command Bar **по очереди**: `Part1_Server.txt` → Enter, затем `Part2_Client.txt` →
> Enter, затем `Part3_World.txt` → Enter.

> **Если в Output появилась красная ошибка** — скопируй её текст и пришли мне.

### Включи красивую графику

Нажми на **Lighting** в окне **Explorer** (справа). В окне **Properties** найди
**Technology** и поставь **Future**. Так свет от Маяка, фонарей и кристаллов будет мягким
и с тенями. Скрипт пытается включить это сам, но Studio иногда не разрешает.

### Сохрани место

**File → Save to Roblox**. Назови игру, например: «Последний Маяк ✦ Last Lighthouse».

---

## Шаг 2. Сохранения прогресса (1 минута)

Чтобы прогресс игроков сохранялся, игра должна быть опубликована и иметь доступ к хранилищу:

1. **File → Publish to Roblox**. Если игра ещё не опубликована — опубликуй её.
2. **Home → Game Settings → Security** → включи **Enable Studio Access to API Services** → **Save**.

Без этого игра работает, но в Studio не сохраняет прогресс. В Output будет предупреждение,
так и задумано.

---

## Шаг 3. Донат: создаём товары (10 минут)

В игре уже есть магазин доната: кнопка **💎 Донат** слева. Осталось создать сами товары
на сайте Roblox и вставить их номера (ID) в игру.

### 3.1. Геймпассы — покупаются один раз, навсегда

1. Открой **create.roblox.com** → **Creations** → выбери свою игру.
2. Слева: **Monetization → Passes** → **Create a Pass**.
3. Создай 3 пасса: название, описание, картинка 512×512.

| Пасс | Что даёт | Рекомендуемая цена |
|---|---|---|
| **VIP Смотритель** | x2 свет навсегда, золотое сияние, значок VIP | 199 R$ |
| **Крылья Смотрителя** | двойной прыжок | 149 R$ |
| **Ещё два духа** | 3 духа одновременно вместо 1 | 249 R$ |

4. Открой каждый пасс → **Sales** → включи **Item for Sale** → поставь цену → **Save**.
5. Скопируй **ID** пасса: это число в адресе страницы или в меню «⋯» → **Copy Asset ID**.

### 3.2. Developer Products — можно покупать много раз

1. Там же: **Monetization → Developer Products** → **Create a Developer Product**.
2. Создай 5 товаров:

| Товар | Что даёт | Рекомендуемая цена |
|---|---|---|
| **Горсть света** | +500 ✦ | 29 R$ |
| **Фонарь света** | +3 000 ✦ | 129 R$ |
| **Сундук звёзд** | +15 000 ✦ | 449 R$ |
| **Зажечь Маяк для всех** | x2 свет всему серверу на 10 минут, все видят твоё имя | 99 R$ |
| **Аврора-Феникс** | легендарный дух: +100% света | 399 R$ |

3. Скопируй **ID** каждого товара.

### 3.3. Вставляем ID в игру

1. В Studio, в окне **Explorer**: **ReplicatedStorage → LastLighthouse → MonetizationIds**.
   Открой его двойным кликом.
2. Замени нули на свои ID, например:
   ```lua
   VIP = 123456789,
   ```
3. Сохрани игру (**File → Publish to Roblox**).

> 💡 Тест в Studio бесплатный: при нажатии «Купить» появится тестовое окно покупки,
> настоящие робуксы не спишутся.
>
> 💡 При повторном запуске установщика твои ID **не сотрутся**.

---

## Шаг 4. Открываем игру для всех

1. **Game Settings → Permissions → Playability: Public**.
2. На create.roblox.com пройди анкету **Maturity & Compliance**. Без неё Roblox не даст сделать
   игру публичной. В нашей игре нет насилия, крови и страшилок, ответы простые.
3. Сделай красивую иконку 512×512 и пару скриншотов. Лучше всего ночью, с лучом Маяка
   и северным сиянием.

## Как приходят деньги 💰

- **Геймпассы и товары.** Ты получаешь около 70% цены в робуксах, остальное забирает Roblox.
- **Premium Payouts.** Roblox сам платит тебе за время, которое в игре проводят игроки с Premium.
  Они, кстати, получают в игре +10% света.
- **Вывод в реальные деньги (DevEx).** По правилам Roblox, известным на момент написания,
  нужно: возраст от **13 лет**, подтверждённая почта, проверка личности и минимум
  **30 000 заработанных робуксов**. Условия и курс иногда меняются — перед выводом проверь их
  на сайте Roblox: create.roblox.com → DevEx. Если тебе нет 18, выводить деньги лучше
  вместе со взрослым.

### Почему донат сделан честно

- Нет случайных «яиц» и лотерей за робуксы. Все покупки понятные, игрок знает, что получит.
  Так проще с правилами Roblox, и игроки больше доверяют.
- Всё можно получить и без доната. Донат ускоряет и украшает, но не делает игру
  «только для платящих».
- «Зажечь Маяк для всех» — самый «вирусный» товар. Покупатель помогает всему серверу,
  его имя видят все. Игроки любят такие вещи.

## Как менять игру

| Хочу… | Где |
|---|---|
| поменять цены, награды, скорость, бонусы | `ReplicatedStorage → LastLighthouse → Config` |
| поменять тексты сюжета и записок | там же, раздел `Config.Story` |
| добавить музыку и звуки | `Config.Sounds`: вставь ID звуков из Toolbox → Audio |
| передвинуть остров, дерево, фонарь | просто двигай их в Studio, игра найдёт их сама |
| добавить осколки света | скопируй любой `ShardSpawn` в `LastLighthouseWorld → ShardSpawns` |

### Для продвинутых: Rojo

Весь код лежит в папке `src/` (рядом с этой инструкцией) и подключается к Studio
через [Rojo](https://rojo.space): `rojo serve` в этой папке, а в Studio — плагин Rojo
→ **Connect**. Мир строится только установщиком: после изменений в `src/` пересобери его командой
`python3 tools/build_installer.py`.
